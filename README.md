# После закрытия — расширенный сценарий

Игра работает в браузере без серверной части и базы данных. Источник мира — читаемый `world.txt`, точная копия предоставленного `library_game_extended.txt`. JavaScript загружает его при публикации на GitHub Pages. Если открываете `index.html` прямо с диска, нажмите «Выбрать world.txt и начать игру» и выберите файл из этой папки.

Для публикации этой игры включите GitHub Pages в Settings → Pages и выберите основную ветку с корневой папкой `/`. Главная страница находится в `index.html`. Все пути относительные.

В новом сценарии работают 10 помещений на нескольких уровнях, скрытый проход в читальню, закрытая дверь кабинета, предметы и их применение, кот с медленным движением и условными диалогами, действия «Погладить кота» и «Отдать мышь», случайные события и четыре концовки. Карта открывается постепенно: посещённые и доступные соседние комнаты подписаны именами. Названия сторон света используются только внутри TXT для построения карты и не показываются игроку. Над картой всегда есть кнопки соседних помещений, поэтому Чердак и Подвал видны с Лестницы даже тогда, когда их карточки находятся за пределами видимой части карты. Закрытый переход помечен замком; нажатие показывает причину. Для случайных событий считаются только переходы между комнатами: первый шанс появляется после четвёртого перехода, следующие — через 3–5 переходов. При подходящем событии берётся случайное; неповторяющиеся события запоминаются.

У каждой из десяти локаций есть отдельная широкая иллюстрация. Картинки WebP сжаты для быстрой загрузки; изображение Холла сохранено в PNG. На странице показывается сцена текущей локации.

При загрузке появляется стартовый экран с коротким вступлением. «Начать игру» создаёт новую игру; если для этого TXT есть сохранение, доступна кнопка «Продолжить игру». Прогресс автоматически сохраняется в localStorage этого браузера после игровых действий: комната, посещения, предметы, найденные объекты, действия, события, состояние персонажей и диалог. При изменении TXT прежнее сохранение не подставляется к новому миру. Перезагрузка страницы показывает стартовый экран, откуда можно продолжить.

Звук включается вручную кнопкой в верхней части игры. Рядом есть ползунок громкости; начальное значение тихое. Каждое помещение получает собственную спокойную мелодию и темп, вычисленные из его названия, поэтому новые помещения в другом TXT тоже получают свою тему. Игра создаёт короткие музыкальные ноты и редкие звуки страниц, часов, дерева или капель средствами браузера. Непрерывного гула нет. Для звука не нужны файлы, интернет или сервер. При выключении звука и при скрытии вкладки воспроизведение останавливается.

Игра учитывает дополнительные строки сценария: `УСЛОВИЕ` у переходов и связей, `ЭФФЕКТ` у предметов и действий, `ДЕЙСТВИЕ:` внутри описания объекта или результата применения, `(ПОСЛЕ: флаг)` у описания объекта, `ДОПОЛНЕНИЕ` у концовки и `ТЕКСТ (по очереди)` для действий с котом. Условные диалоги открываются при выполнении флага. Названия объектов в разных падежах сопоставляются с объявлением, если соответствие однозначно; например, `[письменным столом]` ведёт к `[письменный стол]`.

Для подвала нужен фонарик, который может принести кот на лестнице во время случайного события. Из подвала можно взять ключ №2, затем открыть кабинет и найти том «Ночной каталог». Возврат тома на полку открывает скрытую читальню. Есть ещё выход через чердак, обычная дверь и возможность дождаться утра в кресле.

Состояние хранится в localStorage на том же адресе сайта и в том же браузере. «Начать сначала» и «Начать игру» заменяют сохранение новым прохождением. TXT выводится как текст; HTML из него не исполняется. Произвольные фразы условий не исполняются как код: поддерживаются явно описанные в сценарии флаги, соединения `и`/`или`, проверки посещения, счётчик ходов, открытие связанного объекта и соответствие кнопки концовке.

Проверки: `node scenario-test.cjs`. Браузерный тест: `node scenario-browser-test.cjs` (только для разработки; нужны Playwright и установленный Microsoft Edge). Проверены четыре концовки, условия переходов, действия с котом, несколько предметов, сброс и мобильная ширина 375 px.
